# Pig-Butchering-Scam-Forensics

A collection of forensic scripts and tools for analyzing and combating pig butchering scam campaigns.

## 01. STIX 2.1 Converter

This Python script processes raw text files containing malicious IP addresses and domains, and converts them into standardized **STIX 2.1 Bundles** (`pig_butchering_threats.json`) for threat intelligence sharing.
